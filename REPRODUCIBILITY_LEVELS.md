# Reproducibility Levels & Quality Taxonomy

This document establishes the reproducibility classification framework used across the FedLearn artifact, aligned with ACM/IEEE Artifact Review guidelines.

---

## 1. Classification Definitions

| Level | Name | Definition | Verification Mechanism |
| :---: | :--- | :--- | :--- |
| **R1** | **Conceptual / Specification** | Algorithmic and mathematical principles defined in manuscript text; no automated artifact provided. | Human peer review. |
| **R2** | **Runnable Code** | Source code, models, and scripts are provided and execute cleanly without runtime errors. | Interpreter execution (`make test`). |
| **R3** | **Machine-Traceable** | Empirical numbers are generated by seeded scripts and archived with dataset SHA-256 digests; re-runs reproduce paper metrics within pre-declared statistical tolerance bounds ($\Delta \le \text{tol}$). | `verification/compare_results.py`, `scripts/check_traceability.py`. |
| **R4** | **Deterministic Bit-Level / Machine-Checked** | Formally machine-checked proofs (0 `sorry`, 0 unproved axioms) or deterministic bit-for-bit algebraic identity. | Lean 4 proof compiler (`lake build`), checksum verification (`make verify-manifest`). |

## 3. Pre-Declared Statistical Tolerances for R3 Verification

Because federated stochastic gradient descent (SGD) and gradient-boosted decision trees (XGBoost) involve localized mini-batch stochasticity across different CPU SIMD microarchitectures, re-executions are evaluated against the following strict tolerances:

- **Origin Attribution Accuracy (Top-1):** $\pm 0.030$ (3 percentage points)
- **Compromise Timing Estimation Error (MAE):** $\pm 0.35$ rounds
- **Zero-Day Propagation Delay ($\tau_{0.80}$):** $\pm 0.50$ rounds
- **Zero-Day Peak & Final Recall:** $\pm 0.025$ (2.5 percentage points)
- **Catastrophic Forgetting:** $\pm 0.005$ (0.5 percentage points)
